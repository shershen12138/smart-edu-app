# 问题定义与产品描述 —— 课码（Python 教学实践智能辅导系统）

> 文档版本：v1.0
> 对应任务：需求规格 / 问题定义（problem_definition）
> 产品定位：面向 Python 教学实践课程的智能教学辅助平台，覆盖「作业提交 → 智能/人工批改 → 学情诊断 → 可视化 → 个性化辅导」全流程闭环。

---

## 1. 产品描述 (Product Description)

### 1.1 一句话定位

**课码**是一款面向 Python 教学实践课程的智能教学辅助系统：通过"作业提交 → 智能/人工批改 → 学情诊断 → 可视化 → 个性化辅导"的闭环，帮助教师减负、帮助学生精准补齐知识短板。

### 1.2 产品描述（详述）

课码针对高校 Python 编程教学中"**教师批改负担重、学情难以量化、学生短板无人针对性辅导**"三大痛点而生。系统支持学生在线提交 Python 代码作业，由**机器自动批改**（单元测试 + 静态分析）与**教师人工批改**相结合；在此基础上，系统持续**解析学生历次提交的代码**，识别其在特定知识点上的缺陷，并以**知识图谱 / 学情仪表盘**的方式可视化呈现；内置的**智能辅导 Agent** 可对学生答疑，并针对其薄弱知识点自动生成练习题，形成"诊断 → 练习 → 再诊断"的个性化学习闭环。

### 1.3 核心价值

* **对教师**：把重复批改时间转化为学情洞察与精准教学，班级整体薄弱点一目了然。
* **对学生**：把"做错题"转化为"补对知识点"，学习过程可见、可量化、有反馈。
* **对学校**：支持私有化部署，满足教学数据"不出校"的合规要求。

---

## 2. 5W1H 报告

### What（是什么 / 解决什么问题）

* **产品形态**：B/S 架构的 Web 教学辅助平台，包含学生端、教师端与管理端。
* **解决的核心问题**：
  1. 教师逐份批改代码作业耗时巨大，难以兼顾全班；
  2. 学生是否真正掌握某知识点缺乏量化依据，错误原因难以定位；
  3. 传统 OJ 只判对错、不给解释，学生短板无人针对性辅导；
  4. 班级整体学情不可见，教师难以据此调整教学重点。

### Why（为什么做 / 动机与必要性）

* **教学痛点刚性**：Python 是基础必修课，班级规模大、作业频次高，纯人工批改难以为继。
* **政策与技术契机**：国家"AI + 教育"受政策支持，大语言模型（LLM）与代码分析技术成熟，使个性化辅导从理想走向可落地。
* **差异化空白**：现有 OJ / MOOC 普遍缺少"课堂级学情诊断 + 校内私有化部署"，课码正切入该空白。
* **学习目标对齐**：编程能力依赖刻意练习与即时反馈，课码用数据驱动实现"因材施教"。

### Who（目标用户 / 干系人）

* **核心用户**：高校 / 职业院校的 Python 课程**教师**与**学生**。
* **次要用户**：培训机构讲师、教务处（关注教学数据合规）。
* **干系人**：学校 IT 部门（部署运维）、课程组（知识点体系维护）、任课教师（使用与反馈）。
* **系统角色**：学生（提交 / 练习 / 答疑）、教师（布置 / 批改 / 看板）、管理员（权限 / 审计 / 部署）。

### When（适用时间 / 项目阶段）

* **使用时间**：学期内常态化使用，覆盖"布置作业 → 提交 → 批改 → 复习"全周期；期末可用于学情复盘与成绩佐证。
* **项目阶段**：本期完成需求定义与核心 MVP（批改 + 诊断 + 看板）；后续迭代知识图谱与 Agent 能力。
* **时机窗口**：高校数字化转型期，对智能教学工具需求迫切，先发优势明显。

### Where（使用场景 / 部署环境）

* **使用终端**：校园机房、学生自带设备（笔记本 / 手机），通过浏览器访问，支持响应式。
* **部署环境**：校内服务器**私有化部署**（推荐）或教育专有云，满足"数据不出校"。
* **集成场景**：可经 **LTI 1.3** 嵌入现有 LMS（学习通、Canvas、Moodle），不打断原有教学习惯。
* **网络要求**：校内网或学校 VPN 访问；学生代码沙箱执行需隔离环境。

### How（如何实现 / 技术路径）

* **总体架构**：前端（Vue / React）+ 后端服务（Python 为主）+ 关系数据库 + 消息队列，核心模块低耦合、可独立扩展。
* **批改引擎**：容器化沙箱执行学生代码（限制 CPU / 内存 / 网络 / 文件系统），结合单元测试执行与静态分析（AST / 复杂度 / 规范检查）。
* **学情诊断**：对学生历次提交做知识点维度建模，聚类错误模式，计算各知识点掌握度评分。
* **可视化**：知识图谱（知识点依赖关系 + 掌握度着色）、学情仪表盘（班级 / 个人多维指标）、学习轨迹时间线。
* **智能 Agent**：基于 LLM 的答疑与出题，结合诊断结果定位薄弱知识点并生成针对性练习；支持热插拔不同 LLM 供应商。
* **安全合规**：RBAC 权限控制、传输层加密、关键操作审计日志、私有化部署满足教育数据合规。
