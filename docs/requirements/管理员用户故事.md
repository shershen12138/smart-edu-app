# 管理员用户故事：US-A2 作业上传与版本管理后台

> 项目：Python 教学实践课程系统 ｜ 版本：v1.0 ｜ 日期：2026-10-24
> 模板：作为一名[角色]，我想要[某种功能]，以便能够[实现某种价值]。

---

## 用户故事

- **角色**：作为一名系统管理员
- **功能**：我想要在后台统一配置各班级作业的上传窗口、文件类型与大小限制，并查看全部提交记录及其历史版本
- **价值**：从而以一套策略管理所有班级的作业流转，出现争议时（如"我提交过了"）可以追溯到具体版本和时间戳。

---

## 验收标准（Acceptance Criteria - Gherkin 语法）

```gherkin
场景: 配置作业上传策略
  Given 管理员在后台"作业策略"页面
  When 管理员将默认策略设置为"允许 .py 与 .zip、单文件不超过 20MB、截止前可重复提交"并保存
  Then 该策略应即时对所有未发布该策略的班级生效
  And 教师端创建新作业时应默认引用该策略且可查看策略详情

场景: 追溯学生提交版本
  Given 某学生针对某作业已提交 3 个版本
  When 管理员在后台提交记录中搜索该学生
  Then 系统应按时间顺序列出全部 3 个版本及其提交时间戳、文件哈希
  And 管理员应能下载任意历史版本

场景: 上传非法文件被拦截
  When 某学生尝试上传一个 50MB 的 "homework.exe" 文件
  Then 系统应拒绝上传并提示"文件类型或大小不符合要求（仅允许 .py/.zip，不超过 20MB）"

场景: 截止后提交被拦截
  Given 某作业的上传窗口已关闭，且教师未开启"允许补交"
  When 某学生尝试提交一个合法的 "homework.py" 文件
  Then 系统应拒绝提交并提示"作业已截止，如需补交请联系教师"
  And 系统不应在提交记录中生成新的版本条目

场景: 导出提交记录明细
  Given 某班级某次作业共有 40 名学生提交
  When 管理员在后台提交记录页点击"导出明细"
  Then 系统应在 15 秒内生成包含全部提交的 Excel 文件并触发下载
  And 每行记录应包含：学号、姓名、提交版本数、最新提交时间戳、最新版本文件哈希
```
