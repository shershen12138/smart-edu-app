用户故事一：作业上传与自动批改结果查看

### 故事描述

| 要素              | 内容                                          |
| --------------- | ------------------------------------------- |
| **角色（Role）**    | 作为一名修读 Python 课程的学生                         |
| **功能（Feature）** | 我想要在系统中上传我的 Python 作业代码，并快速查看机器批改结果和教师评语    |
| **价值（Value）**   | 以便我能在提交后第一时间了解代码的正确性与问题所在，及时修正而不是等到下次课才知道错了 |

**故事陈述**：作为一名修读 Python 课程的学生，我想要上传 Python 作业代码并查看机器批改结果与教师评语，以便第一时间发现并纠正代码问题、巩固课堂所学。

### 验收标准（Acceptance Criteria — Gherkin 语法）

```gherkin
场景：成功上传一份有效的 Python 作业
  Given 用户已登录学生账号并进入"我的作业"页面
  When 用户点击"上传作业"按钮并选择一个不超过 10MB 的 ".py" 或 ".zip" 文件
  Then 系统应在 3 秒内完成上传并在作业列表中显示"已提交"状态
  And 系统自动触发机器批改，并在 60 秒内展示运行结果、测试用例通过率与代码评分
  And 页面状态栏应显示"机器批改完成，等待教师复核"

场景：上传格式不符的文件
  Given 用户已进入"上传作业"对话框
  When 用户选择了一个 ".exe" 格式的文件
  Then 系统应立即提示"仅支持 .py 或 .zip 格式，请重新选择"
  And 系统不应发起上传请求，也不产生任何作业记录

场景：查看教师手工批改结果
  Given 用户提交的作业已被机器批改完成
  When 教师在后台完成手工复核并提交评语后
  And 用户打开该作业的详情页
  Then 用户应能看到教师评语、逐题得分及机器批改与人工批改的最终合并成绩
  And 系统应向用户推送一条"作业已批改"的消息通知

场景：上传过程中网络中断
  Given 用户正在上传一份 8MB 的 ".zip" 作业文件
  When 网络在上传过程中中断超过 10 秒
  Then 系统应提示"网络异常，上传失败"并提供"重试"按钮
  And 重试成功后作业状态应恢复正常，且不会产生重复提交记录
```

## 用户故事二：薄弱知识点可视化与 Agent 强化练习

### 故事描述

| 要素           | 内容                                                                       |
| ------------ | ------------------------------------------------------------------------ |
| **角色（Role）** | 作为一名修读 Python 课程的学生                                                      |
| **功能（我想要）**  | 我想要在仪表盘上看到基于我历次作业代码分析出的知识点掌握情况（知识图谱/仪表盘），并让 AI Agent 针对薄弱知识点为我答疑和生成强化练习题 |
| **价值（以便）**   | 以便我能直观定位自己在具体知识点（如切片、闭包、异常处理）上的缺陷，通过针对性练习高效补强，而不是盲目刷题或反复犯同样的错误           |

**故事陈述**：作为一名修读 Python 课程的学生，我想要查看基于历次作业生成的知识点掌握度可视化，并让 AI Agent 针对薄弱点答疑和出题，以便精准弥补知识缺陷、提升学习效率。

### 验收标准（Acceptance Criteria — Gherkin 语法）

```gherkin
场景：查看知识点掌握度仪表盘
  Given 用户已登录且至少有 3 次已被批改的作业记录
  When 用户进入"学习分析"页面
  Then 系统应在 5 秒内渲染出知识点仪表盘，展示各知识点的掌握度（0-100%）与错误次数
  And 掌握度低于 60% 的知识点应以醒目颜色（如红色）标记为"薄弱"
  And 用户可切换"知识图谱"视图，查看知识点之间的前置依赖关系

场景：系统识别特定知识点的代码缺陷
  Given 用户历次作业中在"列表切片"知识点上累计出现 4 次典型错误（如负索引越界、步长误用）
  When 系统完成最新一次作业的代码分析
  Then 系统应将"列表切片"的掌握度下调并标记为薄弱知识点
  And 仪表盘上该知识点的详情中应列出具体的错误代码片段及错误原因说明

场景：与 AI Agent 答疑互动
  Given 用户在仪表盘中点击了薄弱知识点"列表切片"
  When 用户点击"向 AI 助教提问"并输入"为什么 my_list[5] 会报 IndexError？"
  Then Agent 应在 10 秒内返回与该知识点相关的中文答疑内容
  And 回答内容应引用用户自己代码中的实际片段进行解释

场景：生成并完成强化练习
  Given 用户的知识图谱中"列表切片"被标记为薄弱知识点
  When 用户点击"生成强化练习"按钮
  Then 系统应在 15 秒内生成 5 道针对该知识点的 Python 练习题（含代码填空或编程题）
  And 用户提交答案后，系统应即时判定对错并给出解析
  And 练习完成后，该知识点的掌握度应根据练习成绩自动更新仪表盘数值

场景：无足够历史数据时的降级展示
  Given 用户上传的已被批改的作业少于 3 次
  When 用户进入"学习分析"页面
  Then 系统应提示"作业数据不足，完成更多作业后可生成学习分析"
  And 页面不渲染空白图表，且提供"去完成作业"的跳转入口
```
