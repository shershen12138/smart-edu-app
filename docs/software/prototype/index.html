交互式原型（docs/software/prototype）

本原型由 AI 依据仓库现有页面与需求文档生成，用于演示管理员、教师、学生三类角色的界面与关键交互。 页面使用静态示例数据，不连接数据库、不执行任何学生代码、不产生真实批阅成绩。

进入登录页 直接看管理员端 直接看教师端 直接看学生端

管理员

  • 教师 / 学生账号 CRUD、CSV 导入预览
  • 教学班 CRUD 与归档恢复
  • 数据字典与字典项维护
  • 按教学班设置作业、成绩、导出权限
打开原型

教师

  • 机器 / 非机器批阅作业创建与时限调整
  • 提交记录、期望与实际结果查看
  • 逐题人工评分与评语、班级统计
  • 学生代码质量报告与六维雷达图
打开原型

学生

  • 机器批阅提交单个 .py
  • 非机器批阅提交 1001.py～1005.py 的 ZIP
  • 查看得分、评语（不显示答案）
  • 查看自己的代码质量报告与雷达图
打开原型

原型包含的可交互点

登录页

账号密码校验提示；勾选“首次登录”后进入强制改密流程，校验新密码长度与两次一致性。

管理员端

名单分页与启停、删除二次确认、新建账号弹窗（学号重复校验）、批量导入预览（成功 / 失败行）、数据字典增删、班级归档开关。

教师端

批阅方式切换联动上传说明、作业创建后列表刷新、提交记录切换、逐题评分滑块实时合计与保存、六维量规滑块联动雷达图与综合分。

学生端

.py / ZIP 文件类型校验、提交进度条（明确标注为原型模拟）、结果页只显示得分与评语、我的质量报告雷达图。
