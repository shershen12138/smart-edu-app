创建作业

机器批阅包需为完整章节 ZIP。网站只静态解析，标准答案在工作进程的 Docker 容器中验证一次并生成私有标准结果，验证通过后等待中的提交自动入队。

代码质量报告与六维量规

六个维度按 5 分制打分：5=全部达标；4=核心达标；3=思路对但有关键错误；2=多处错误；1=未实现或不可解析。 拖动下方分值，右侧雷达图与综合分会实时更新（示例数据，不代表任何真实学生成绩）。

静态评测不执行学生代码，缺陷为“疑似”结论，需教师用样例数据复核；报告不把静态推断写成运行通过或运行失败。
