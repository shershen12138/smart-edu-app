## 规则

- 账号由管理员创建，不依赖邮箱。默认临时密码 123456；新建、重置及三个测试账号均强制首次改密。按当前试用要求取消长度、常见密码及全数字等复杂度校验，首次改密与两次输入一致检查仍保留。
- 按用户要求暂存明文密码副本，只在管理员编辑页展示，由 `STORE_RECOVERY_PASSWORDS` 控制；后续正式安全整改需另行关闭并清理。删除账号、教学班或作业时实际删除对应记录、关联数据和专用文件；学生/教师账号不会随教学班删除。删除教师后，其已布置作业仍归教学班保留。
- 教师上传的机器批阅包或人工批阅材料保存在私有目录，题目说明按班级/角色鉴权查看和下载。
- 两种 ZIP 作业都在“修改作业”页支持选择包内单个文件上传替代版本，系统重建不可变 ZIP。机器批阅仅更新 Word 说明文档时不重评；更新 `sample*.py` 或其他批阅文件须经 Docker 验证，成功后归档旧成绩并重评已有提交，失败继续使用旧版本，并提供具体错误及重新验证入口。非机器批阅材料更新不调用 Docker且不改动已有人工成绩。作业详情和班级结果页显示本次重评的成功、剩余及失败数量；全部成功后醒目提示消失，结果保留在版本更新记录中。
- 机器批阅每次提交一个不超过 128 KB 的 UTF-8 `.py`；人工批阅提交包含 `1001.py`～`1005.py` 的答案 ZIP。每份作业默认最多 20 次，不允许截止后提交，同一请求不会生成重复记录。
- 每题按通过用例数占全部用例的比例计分；作业总分为各题得分之和。返回值比较沿用原批卷器的严格类型规则，浮点数和复数允许 `1e-6` 误差。以最后一次提交作为当前成绩；历史提交可回看。
- 平台异常或未配置不产生数值成绩。统计仅针对当前在班学生，均分仅含已批阅结果，报表明确区分未交/待批阅/异常。
- 第 1～9 章采用函数式机器批阅；第 10 章采用教师人工逐题评分。新建作业必须上传与批阅方式对应的 ZIP。
- 教师不用在网页上配置测试用例；机器批阅 ZIP 已包含标准答案、函数清单和测试数据。后台导入、绑定命令只用于维护和历史作业。
- 教师可查看用例期望结果和学生实际返回值，学生端不输出答案；升级前未存储的实际结果显示未记录。两种批阅方式都支持按班打包下载每名学生最后一次提交及打包结果；人工答案 ZIP 在下载包中直接展开，不嵌套 ZIP。
- 导入后显示处理、新增及已有账号数量，单班导入跳转到该班名单。名单、教学班及报表人数口径一致，支持总人数、每页条数、连续序号和页码跳转。授权选择显示班级编号、名称和学期。
- 管理员不从名单页进入“本班作业”，教师作业管理入口也不对管理员开放。
- 按教学班归档后，所有角色日常页面和旧详情/下载链接均不可访问该班内容；管理员在专用归档页取消勾选后恢复数据及授权。仅属于归档班的学生账号从日常名单隐藏；同时属于其他正常班的账号仍可在对应班管理。
- 当前迁移到 `0009`，包括私有文件清理重试队列与实际返回值字段；旧业务路由不对外开放。删除时兼容清理旧表关系，必要操作日志保留，仍被其他作业引用的文件不删除。

学校采用 Ubuntu 24.04、Docker、MySQL、Redis 和 Celery。2026-10-06 已完成本地 SQLite / MySQL 回归、MySQL 0008→0009 升级及真实 Docker 测试；学校现场升级、校内跨网段连通性和集中提交负载需在目标环境验收。安装与升级入口分别见 `GETTING_STARTED.md` 和 `../deploy/linux/README.md`。
