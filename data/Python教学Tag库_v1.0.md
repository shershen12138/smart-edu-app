> **大纲来源**：`school/portal/data/python_graph.json` 的节点树（一级 5 个模块 / 三级 / 四级节点）。
> **结构**：`#` 图谱一级模块 → `##` 图谱三级节点 → `###` 图谱四级节点 → `-` 节点首选 tag → 缩进 `-` 原有细化 tag。
> **首选名**：节点行本身即该节点的**首选 tag**，图谱名称优先；同义旧名并入其下并保留为别名。
> **关联**：节点行 `@<node_id>` 与图谱 JSON 的 `node.id` 同名；tag 行末尾 `@Uxx-Mxx` 是它原来的教学模块，能力画像仍按它映射。
> **未入图**：图谱尚未建节点的模块保留在附录 A，等图谱扩展后整体迁入。
