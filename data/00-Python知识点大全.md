## 一、程序结构与编码

1. 源文件编码声明：`# -*- coding: utf-8 -*-`
2. 语句换行：一行一条语句，行尾不需要分号（写了也不报错）
3. 缩进即语法：用 4 个空格表示代码块，同一代码块缩进必须一致
4. 注释：单行 `#`；多行用三引号字符串 `'''...'''` 或 `"""..."""`
5. `pass` 空语句占位
6. `if __name__ == "__main__":` 程序入口写法
7. 标识符命名规则：字母/数字/下划线，不能以数字开头，区分大小写
8. 关键字不能作变量名（if、for、while、def、class、import、return…）

## 二、输出与输入

9. `print()` 输出，多个值默认以空格分隔：`print(a, b)`
10. `print(..., sep=",")` 自定义分隔符
11. `print(..., end="")` 不换行输出
12. f-string 格式化：`f"点{(x2,y2)}在圆内"`
13. `%` 格式化与 `str.format()`（了解即可）
14. `input()` 返回的一律是字符串，需 `int()` / `float()` 转换后再计算

## 三、变量与数据类型

15. 变量无需声明类型，赋值即创建（动态类型）
16. 整数 `int`（无限精度）
17. 浮点数 `float`（有精度误差：`0.1+0.2 != 0.3`）
18. 布尔 `bool`：`True` / `False`（首字母大写）
19. 字符串 `str`（不可变序列）
20. 列表 `list`（可变序列）
21. 元组 `tuple`（不可变序列）：`(user1, "password1")`
22. 字典 `dict`（键值对）：`{'name': '', 'age': 0}`
23. 集合 `set`（去重、无序）
24. `None` 空值
25. 类型查看：`type(x)`、`isinstance(x, int)`
26. 类型转换：`int()`、`float()`、`str()`、`list()`、`tuple()`、`bool()`
27. 进制转换：`int(num, 16)` 十六进制转十进制、`bin()`、`hex()`、`oct()`

## 四、运算符与表达式

28. 算术运算符：`+ - * /`（`/` 结果必为 float）
29. 整除 `//`、取余 `%`、幂 `**`
30. `num % 2 == 0` 判断奇偶；`num % 3 == 0` 判断整除
31. `num //= 2` 等增强赋值：`+= -= *= /= //= %= **=`
32. 比较运算符：`> < >= <= == !=`
33. 链式比较：`0 <= num <= 100`（等价于 `0<=num and num<=100`）
34. 逻辑运算符：`and or not`（短路求值）
35. 成员运算符：`in` / `not in`（可用于 list、str、tuple、dict、set）
36. 身份运算符：`is` / `is not`
37. 三元条件表达式：`a if 条件 else b`，如 `num1 if num1>num2 else num2`
38. 运算符优先级：算术 > 比较 > 逻辑；不确定就加括号

## 五、字符串操作

39. 引号：单引号、双引号等价；三引号可跨行
40. 下标索引：`s[0]` 正向、`s[-1]` 反向（末位）
41. 切片：`s[start:stop:step]`，左闭右开；`s[::-1]` 反转
42. `len()` 求长度
43. 拼接 `+`、重复 `*`
44. 遍历字符串：`for ch in s:`
45. 大小写：`s.upper()`、`s.lower()`、`s.isupper()`、`s.islower()`
46. `ord()` 字符→Unicode 码，`chr()` 码→字符
47. `str.isdigit()`、`str.isalpha()` 等判断方法
48. `str(x)` 与数字互转；逐位取数字：`[int(c) for c in str(1234)]`
49. 字符串比较按字典序（Unicode 码点）

## 六、列表操作（重点）

50. 创建：`[]`、`list()`、`[0]*n`
51. 索引与负索引：`A[0]`、`A[-1]`
52. 切片：`A[7:15]`、`A[:t2]`、`A[t2+2:]`、`A[pos[0]:pos[1]-1:-1]`（负步长切片）
53. `len(A)` 元素个数
54. 追加：`A.append(x)`（尾部加 1 个）、`A.extend(B)` / `A + B`（合并）
55. 插入：`A.insert(i, x)` 在下标 i 处插入
56. 删除：`del A[j]`、`del A[i:j]`、`A.pop(i)`、`A.remove(x)`（按值删首个）
57. 查找：`x in A`、`A.index(x)`、`A.count(x)`
58. 排序：`A.sort()`（原地、升序）；`A.sort(reverse=True)` 降序；`sorted(A)` 返回新列表
59. 自定义排序键：`A.sort(key=lambda item: (item[1]+item[2], -item[0]))`（多级排序、元组键）
60. 反转：`A.reverse()`、`A[::-1]`
61. 求和/最值：`sum()`、`max()`、`min()`；`max(t1)` 与 `t1.index(mx)` 配合找最值下标
62. 列表遍历：`for x in A:`；带下标遍历：`for i in range(len(A)):`
63. 列表推导式：`[i for i in A if type(i)==int]`
64. 嵌套列表（二维列表/矩阵）：`A[row][col]`，转置写法 `[A[row][col] for row in range(len(A))]`
65. 列表是可变对象：函数内 `sort()`、`append()` 会修改原列表（注意副作用）
66. 浅拷贝陷阱：`B = A` 只是引用，`B = A[:]` / `list(A)` 才是复制
67. 多重赋值与交换：`a, b = 0, 0`、`a, b = b, a`
68. 解包：`ret1, ret2 = 0, 0`；函数返回元组可解包接收

## 七、元组与字典

69. 元组创建与不可变性；单元素元组要写 `(x,)`
70. 元组可用于成员判断：`(username, password) not in user_info`
71. 字典创建：`{}`、`{'name': '', 'age': 0}`
72. 取值/赋值：`d['name']`（键不存在会 KeyError）
73. `d.get(key, 默认值)` 安全取值
74. 遍历键值：`for k in d:`、`for k, v in d.items():`
75. 键必须是不可变类型（str、int、tuple 可以）

## 八、条件分支结构

76. 单分支：`if 条件:`
77. 双分支：`if ... else:`
78. 多分支：`if ... elif ... else:`（elif 可多个，顺序自上而下命中即停）
79. 分支嵌套：`if` 里面再套 `if`（注意缩进层次）
80. 条件表达式结果是 bool；非空/非零即真
81. 常见组合判断：`a+b<=c or a+c<=b or b+c<=a`
82. `math.isclose(a, b)` 浮点数近似相等比较（直角三角形判断）
83. 区间判断写法：`60 <= i and i <= 89` 或链式 `60 <= i <= 89`
84. 分支覆盖完整性：每个分支都要有返回值，漏写 else 会返回 None

## 九、循环结构（重点）

85. `for i in range(n):` → 0 ~ n-1
86. `range(a, b)` → a ~ b-1；`range(a, b, step)` 步进；`range(len(A)-1, i, -1)` 反向
87. `for x in 列表/字符串:` 直接遍历元素
88. `while 条件:` 先判断后执行，条件为假才结束
89. `while` 实现"除 2 取余"进制转换：`while num != 0: ret = str(num%2)+ret; num //= 2`
90. `while True` + `break` 死循环跳出模式
91. `break`：跳出本层循环
92. `continue`：跳过本次循环体剩余部分
93. 循环 `else` 子句：循环未被 `break` 中断时执行（`for...else` / `while...else`）
94. 嵌套循环：外层控制行、内层控制列（九九表、矩阵、素数判断）
95. 双重循环中的标志位模式：`flag = 0; ...; if 条件: flag = 1; break`
96. 循环变量手动控制步进：`i = i - 1`（while 内千万别忘，否则死循环）
97. 素数判断模板：`range(2, int(n**0.5)+1)` 内找因子
98. 累加器模式：`total = 0` 循环内 `total += x`
99. 计数器模式：`count += 1` 分类计数（奇偶、分数段）
100. 枚举所有组合：三层 `for i / for j=i+1 / for k=j+1`

## 十五、常见错误清单（学生作业高频 Bug）

150. 漏写冒号 `:`（SyntaxError）
151. 缩进不一致（Tab 与空格混用）
152. `=` 赋值与 `==` 判等混用
153. 中文标点（，：（）""）混入代码
154. 切片左闭右开理解错：`A[7:15]` 取不到下标 15
155. `range(a, b)` 取不到 b，差一错误（off-by-one）
156. 负索引越界或用错：`A[-1]` 是末位不是"不存在"
157. 修改正在遍历的列表（边遍历边 del）导致漏删
158. `int` 与 `float` 混算：`//` 得 int，`/` 得 float
159. 字符串与数字直接 `+` 拼接（TypeError）
160. `int('abc')` 或对非字符串调用 `str()` 方法（TypeError/ValueError）
161. 忘记 `return`，函数返回 None
162. 分支条件顺序错误（大范围在前把小范围拦截）
163. 边界值遗漏：`<` 与 `<=`、`0`、空列表、单元素
164. `while` 循环变量忘记更新 → 死循环
165. `break` 只跳一层嵌套循环
166. sort 的 key 写反（升序/降序、负号漏加）
167. 浮点数直接 `==` 比较（应使用 `math.isclose` 或误差范围）
168. 命名冲突：变量名覆盖内置函数（如 `sum = 0` 后再用 sum()）
169. 布尔值与整数混淆：`isPrime(c)==True` 可简写
170. 未处理空列表/空字符串的特例
